# File Nexus Suite

텍스트·전자책·미디어 파일 작업에 특화된 통합 파일 도구입니다.
An integrated file utility for text, e-book, and media file management.

| Tab | 기능 / Feature |
|---|---|
| Text Merger | 여러 파일을 하나의 텍스트로 병합 / Merge multiple files into one (TXT, DOCX, PDF, XLSX) |
| Text Converter | TXT ↔ EPUB 형식 일괄 변환 / Batch convert between TXT and EPUB |
| Tag Editor | 파일명 태그 일괄 추가·제거 / Batch add/remove filename tags, strip zero-padding |
| Batch Renamer | 파일명 일괄 변경 / Batch rename with prefix, numbering, find & replace |
| Text Fixer | 줄바꿈 교정 — 단락 병합·빈 줄 정리 / Fix line breaks — merge paragraphs, compress blanks |
| Bulk Fixer | Text Fixer를 여러 파일에 일괄 적용 / Apply Text Fixer to multiple TXT files at once |

## 주요 특징 / Highlights
- 🌏 5개 언어 / 5 languages (한국어 · English · 日本語 · 中文简体 · 中文繁體)
- 🎨 9개 테마 / 9 themes (Light · Dark · Sakura · Ocean · Mint · Sand · Honey · Lavender · Choco)
- ⌨️ 단축키 커스터마이징 / Customizable shortcuts
- 📁 전역 출력 폴더 · 저장 후 자동 열기 / Global output folder · auto-open after save
- 🔍 Text Fixer Ctrl+F 검색 / Ctrl+F search in Text Fixer

## 시스템 요구사항 / Requirements
- Windows 10/11 (64-bit)
- 별도 설치 불필요 — exe 실행만 하면 됩니다
- No installation required — just run the exe

1. zip 압축 해제 / Extract zip
2. FileNexusSuite.exe 실행 / Run FileNexusSuite.exe
3. 앱 내 [?] 도움말 참고 / See in-app [?] Help for details
